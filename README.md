# Natural-Policy-Lab
## Efforts to make a natural policy.

Before we get too far into the policymaking, we need to first define what is natural.

Natural life includes, but not limited to:

* Using more instincts
* Attempt to survive and reproduce
* Finding the right environment

However, these needs to be balanced with societal pressures.
